# Jenkins Build Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and archive Tablight from Docker-hosted Jenkins on Linux.

**Architecture:** A Declarative Docker agent runs existing npm commands. Required gates precede release archiving; optional expensive suites and always-published diagnostic reports support VM use.

**Tech Stack:** Jenkins Pipeline, Docker Pipeline, Node.js 22, JUnit.

**Spec:** `docs/superpowers/specs/2026-11-17-jenkins-design.md`

## Global Constraints

- Linux agent labelled `docker`, Node.js 22 build container.
- Keep existing build/release checks and stop on failure.
- No browser store deployment.

## Review Focus

- Stale outputs: clean before checkout and after reporting.
- Failing suites: preserve command failure while publishing reports.
- Optional browser dependencies: install only when requested.
- Containerized Jenkins: document CLI, daemon access and workspace sharing.
- Resource use: bounded timeout and retained artifacts.
