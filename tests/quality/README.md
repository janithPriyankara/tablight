Both fixtures are **synthetic**. They were written by an LLM (Claude), contain **no real user data**, and model realistic tab titles and URLs. Each item is `{ title, url, group }`, using the starter group ids from `src/classify/seeds.ts`. Items labelled `other` are genuinely miscellaneous pages.
- `fixture.json` is the **dev set** (320 items, 28 `other`). The classifier implementer wrote it during Task 5, before the seeds were finalised. Labels follow how a human would file each tab: news by primary topic, subreddits by subject, and so on. It includes hard cases such as YouTube videos on programming, music and AI, IMDb movie vs series pages, and GitHub AI-agent repos vs general repos. Seeds, threshold, k, rules and text shaping were tuned against this set, so its accuracy is optimistic.
- `holdout.json` is the **blind holdout** (200 items, about 14% `other`). A separate agent wrote it without seeing `src/` or `tests/`. It is never used for tuning, and `accuracy.test.ts` prints only aggregate numbers for it. Do not open it to tune against it, or it stops being a holdout.
`accuracy.test.ts` runs the real model (`public/models`, no network) through the caller pipeline: `ruleGroup`, then `assign`, then Unsorted. It asserts ≥ 85% top-1 accuracy on non-`other` items for both sets. It also reports the share of `other` items that get auto-assigned to a real group.
