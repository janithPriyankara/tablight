Tablight: Private AI Tab Organizer
Group, search and save hundreds of tabs by topic, with an AI model that runs on your device. No servers, no tracking.
Tablight helps when you have too many tabs open.
- See all your tabs from every window in one dashboard, automatically grouped by topic such as Movies, Programming, Shopping or News. Drag a tab into another group and it learns your choice. New topics are spotted on their own and offered as new groups, or created automatically if you turn that on.
- Find duplicates and close the extras, with a 10 second undo.
- Points out tabs that opened in the background and look like ads or scams, so you can review and close them together.
- Pause tabs to free memory (they stay in your tab strip and pick up when clicked), or save a tab, a group or a whole window for later: the tab closes and is kept in Saved for later until you open it again.
- Hourly snapshots of your windows let you continue where you left off after a restart.
- Keep it open in the browser's side panel next to your pages: this window's tabs and every group, one click to switch.
- Search by words (typos are fine) or by meaning.
- Recognises about 60,000 well-known names (TV, films, games, music, anime, books, cars, sports, hardware) from an offline list built from Wikidata (CC0), and can optionally look up one unknown name for you, only when you press "Look it up" and confirm the text.
- Export and import a backup file. Saved tabs can sync between your own devices through your browser account.
Private by design: the grouping model is bundled in the extension and runs on your computer. The extension makes no network requests unless you press "Look it up" on an Unsorted tab and confirm; then only the text you saw and could edit goes to Wikimedia's Wikidata and, if that finds nothing, to Wikipedia (both run by the Wikimedia Foundation). It has no servers, accounts or analytics, never reads page contents and ignores private (incognito) windows. It cannot see passwords, cookies, sign-ins, payment details or anything you type: all it receives is each open tab's title and address.
Organize the user's open browser tabs: list, group by topic, find duplicates, pause them or save them for later, and search them.
| Permission | Why it is needed |
|---|---|
| `tabs` | Read the title and address of open tabs to list and group them; switch to, pause, close and create tabs when you ask. |
| `storage` | Keep groups, saved tabs, snapshots and settings on the device, and sync saved tabs and the examples taught to groups through the browser's extension sync storage; keep short-lived suspicious-tab clues (which site opened a tab, pop-up windows, tabs you chose to keep) in session storage until the browser closes. |
| `unlimitedStorage` | Store the tab index and the numeric summaries (embeddings) of tab titles locally, which can exceed the default quota with thousands of tabs. |
| `alarms` | Run auto-pause (off by default) and hourly snapshots while the background worker is idle. |
| `offscreen` | Run the bundled on-device model in an offscreen document, because a service worker cannot host it reliably. |
| `sidePanel` | Show Tablight in the browser's side panel when you open it there (toolbar icon, popup button or Alt+Shift+S). |
| `favicon` | Show site icons from the browser's own icon cache; no icon is downloaded from a website. |
| `tabGroups` (optional) | Requested only if the user turns on mirroring of groups into the browser's native tab groups. |
No host permissions, no content scripts, no remote code.
Reviewer note (network): the CSP `connect-src` is `'self' https://www.wikidata.org https://en.wikipedia.org`. The only requests to those hosts are the optional "Look it up" action: the user clicks it on an Unsorted tab, sees the exact cleaned text (emails, links, @handles, phone and card-style numbers, long numbers and token-like strings removed; editable; for a search page it is the words searched), and nothing is sent until they press "Look up". It is a plain GET to the Wikidata search API (`https://www.wikidata.org/w/api.php`) from the extension page and, only if Wikidata returns no match with a topic, one more plain GET with the same confirmed text to the English Wikipedia search API (`https://en.wikipedia.org/w/api.php`); both with no cookies and no referrer (Wikimedia sees the IP address, browser type and the fixed extension identifier, as any website would), so no host permission is needed (both hosts serve CORS for these APIs) and none is requested. It is refused for non-web, local/private and sensitive tabs. Answers are cached on the device (up to 500), never synced, and removed by "Delete all data". The button can be hidden in Settings. Without a click, the extension makes no network request.

Uninstalling removes the data on the device; turning sync off does NOT remove the synced copy (use "Delete all data" for that). Other devices keep their own copy until "Delete all data" is used there too.
